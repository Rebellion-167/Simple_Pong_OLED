# NanoPONG - OLED Pong Game (Arduino)

NanoPONG is a classic **Pong-style game** developed for a **128x64 SPI OLED display** using an **Arduino Nano**. This project is built mainly for learning and fun, and it follows a clean and modular coding style.

## About the Project

NanoPONG recreates the classic Pong game on a small OLED screen. The game includes a start screen, a countdown before the ball moves, paddle controls, ball movement with collision, scoring, and a winning screen.

The code is divided into multiple header files to keep everything organized and easy to understand.

## Hardware Used

- Arduino Nano
- 128x64 SPI OLED Display
- Push buttons (Up, down, start)
